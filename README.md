# 🧑‍💻 Developer Skill Radar

A modern and responsive **Developer Skill Radar Dashboard** built using **HTML, CSS, JavaScript, and Chart.js**. This project showcases technical skills through an interactive radar chart, animated progress bars, glassmorphism effects, and a professional portfolio-inspired design.

---

## ✨ Features

* 🎯 Interactive Radar Chart
* 📊 Animated Skill Progress Bars
* 🌙 Modern Dark Theme
* 💎 Glassmorphism UI Design
* ⚡ Smooth Hover Effects
* 📱 Fully Responsive Layout
* 🎨 Gradient Skill Indicators
* 🚀 Portfolio Ready Design
* 📈 Animated Percentage Counters
* 🔥 Neon Glow Effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/iqbolshoh/developer-skill-radar.git
```

### 2. Open Project

```bash
cd developer-skill-radar
```

### 3. Run Project

Simply open:

```text
index.html
```

in your browser.

No installation or build tools required.
